# ODB++ Extractor 用户指南

本应用程序专为解析 ODB++ 设计并将元件数据导出为结构化 XML 而设计。

  <img src="images/main_interface_cn.png" height="400" alt="Main Interface" />
</div>

## 1. 支持的输入格式

本应用程序严格处于只读模式，不会修改您的原始设计文件。

* **压缩包:** 对于 `.tgz`、`.tar.gz`、`.zip` 和 `.tar` 文件，请点击 **浏览文件**。
* **目录:** 对于已解压的 ODB++ 文件夹，请点击 **浏览文件夹**。

## 2. 快速提取流程

1. 打开应用程序并加载您的 ODB++ 文件或文件夹。
2. 从下拉菜单中选择目标 **步骤** 和元件 **图层** 。
3. 配置导出选项（原点、单位、坐标轴翻转）以正确映射到您的目标系统。
4. 点击 **预览** 以可视方式验证布局和坐标对齐情况。
5. 导出数据：
   * **导出当前图层:** 为所选层生成单个 XML 文件。
   * **导出全部图层:** 为当前步骤中的每个元件层分别生成 XML 文件。

<div class="page"/>

## 3. 坐标与导出参数

调整这些设置可确保导出的数据与系统的坐标要求精确对齐。更改将立即反映在可视预览和数据表格中。

* **原点:**
  * **左上:** Y 轴数值向下递增。
  * **左下:** Y 轴数值向上递增。
* **单位:** 选择 **毫米** 或 **英寸**。
* **反转坐标:**
  * **反转X轴:** 沿 PCB 宽度镜像所有 X 坐标。
  * **反转Y轴:** 沿 PCB 高度镜像所有 Y 坐标。

## 4. 导出结果

文件将按特定命名规则保存至指定目录：`<job>_<timestamp>_components_<layer>.xml`。

## 5. 可视化验证 (查看器)

内置查看器允许您在导出前检查元件并叠加背景图像（如参考照片）以进行视觉对齐验证。

<div align="center">
  <img src="images/viewer_cn.png" height="400" alt="Viewer" />
</div>

**基本控制:**

* **缩放:** 鼠标滚轮
* **平移:** 按住左键拖动
* **检查:** 点击任意元件查看其封装、中心 X/Y 坐标、宽度、长度和旋转角度。
* **搜索:** 使用侧边栏按名称或封装类型过滤元件。
* **上下文菜单:** 在画布上右键单击以重置视图，或加载、清除、锁定或重置背景图像。

**背景对齐快捷键 (解锁时):**

* **移动图像:** `Ctrl` + `按住左键拖动`
* **缩放图像:** `Ctrl` + `鼠标滚轮`
* **微调缩放:** `Ctrl` + `+` 或 `-`
* **超精细缩放:** `Ctrl` + `Shift` + `+` 或 `-`

## 6. 注意事项

* 导出前，请务必确认目标系统的坐标约定与您的原点、单位及坐标轴翻转设置相匹配。
* 您可以随时按 `Ctrl + Shift + L` 切换应用程序界面语言。
